# API Conventions & Protocols: IronGraph-Engine

## 1. Protocol Architecture
IronGraph-Engine is an asynchronous, headless HTTP/JSON and Server-Sent Events (SSE) service compliant with **OpenAPI 3.1.0**.

- **Base URL**: `http://localhost:8000` (Local) / `https://api.irongraph.internal` (Cloud)
- **Data Exchange**: All JSON payloads must use UTF-8 encoding.
- **Date-Time Format**: ISO 8601 extended format (`YYYY-MM-DDTHH:MM:SS.sssZ`) in UTC.

## 2. Authentication & Authorization
Requests must supply an authorization bearer token:
```http
Authorization: Bearer <JWT_OR_API_TOKEN>
```
The token payload encodes tenant scope:
- `lifters:write`, `lifters:read`: Manage lifter profiles, baseline 1RMs, and volume landmarks.
- `adaptations:write`: Submit daily atypical drawbacks and trigger workout adaptation.
- `exercises:read`: Query the biomechanical exercise graph and request 1:1 substitutions.

## 3. Server-Sent Events (SSE) Streaming Format
The adaptation endpoint (`POST /v1/lifters/{id}/adapt`) streams real-time coaching rationale and structured workout deltas over HTTP SSE.

Clients must specify:
```http
Accept: text/event-stream
Cache-Control: no-cache
```

### Event Types Emitted:
1. `event: token`: Chunked coaching explanations and physiological rationale as generated by the Hypertrophy Agent.
   ```text
   event: token
   data: {"text": "Converting back squats to hack squats to eliminate axial spinal loading."}
   ```
2. `event: workout_delta`: Verified adapted exercise sets, rep targets, loads, and intensifiers in structured JSON.
   ```text
   event: workout_delta
   data: {"exercises": [...], "estimated_duration_min": 28, "total_effective_sets": 9, "sfr_rating": "VERY_HIGH"}
   ```
3. `event: complete`: Final adaptation completion confirmation.
   ```text
   event: complete
   data: {"adaptation_id": "adapt_01HXYZ...", "status": "COMMITTED"}
   ```

## 4. Standard Error Format (RFC 7807)
All error responses adhere to the RFC 7807 Problem Details standard:

```json
{
  "type": "https://irongraph.internal/errors/contraindication-violation",
  "title": "Biomechanical Safety Violation",
  "status": 422,
  "detail": "Exercise 'barbell_back_squat' violates active contraindication 'acute_lumbar_strain'.",
  "instance": "/v1/lifters/f1e2d3c4-b5a6-7890-1234-567890abcdef/adapt"
}
```
